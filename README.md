Un simulador web avanzado de Estructuras de Datos diseñado para visualizar el comportamiento de un **Árbol Binario de Búsqueda Auto-Balanceado (AVL)**. Construido completamente desde cero utilizando HTML5 Canvas y Vanilla JavaScript.

## ✨ Características Principales

*   **Animaciones en Tiempo Real:** Visualización fluida de inserciones, eliminaciones y búsquedas a 60fps.
*   **Rotaciones Automáticas:** Algoritmo que detecta el factor de balanceo y ejecuta rotaciones Simples (LL/RR) y Dobles (LR/RL) de forma visual.
*   **Motor Multitema:** Interfaz personalizable con temas Claro, Oscuro, Drácula y Océano.
*   **Comandos de Voz (Speech API):** Control total del simulador hablando al micrófono (Ej: "Insertar 15", "Drácula", "Limpiar"). Soporte para Español, Inglés, Francés y Portugués.
*   **Sistema de Cámara Inteligente:** Paneo táctil, zoom manual y sistema *Auto-Fit* que ajusta la escala automáticamente para que el árbol siempre sea visible.
*   **PWA Ready:** Instalable en dispositivos móviles para uso sin conexión (Offline).
*   **Gestión de Estados:** Sistema de historial para deshacer/rehacer acciones y guardado local del progreso.

## 🛠️ Stack Tecnológico

*   **Frontend:** HTML5, CSS3 (Variables y Media Queries responsivas).
*   **Motor Gráfico:** API de HTML5 Canvas.
*   **Lógica y Algoritmos:** Vanilla JavaScript (ES6+).
*   **Despliegue:** Render.
